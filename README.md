# 消失井字棋 · 不敗 AI

一個單檔網頁小遊戲：你執 X 先手，對手是用完整遊戲樹搜尋選擇最佳落子的電腦 O。

**線上試玩：<https://wkai2573.github.io/vanishing-tictactoe/>**

## 規則

- 棋盤與連線規則和一般井字棋相同，先連成一線者獲勝。
- 每位玩家最多同時保留 3 顆自己的棋子。
- 下第 4 顆時，自己最舊的那顆會從棋盤上消失。
- 棋盤上的小數字是棋子的年齡，黃色閃爍的格子是下一手落子後即將消失的棋子。
- 對局超過 300 手仍未分出勝負，判為和局。

## AI 原理

- 局面由雙方各自的落子順序與輪到誰決定，因為消失規則讓同一個盤面可以來自不同歷史。
- 以迭代式深度優先搜尋走訪整棵遊戲樹，並用記憶表快取每個局面的結果。
- 搜尋途中遇到重複出現的局面視為循環，以和局計算。
- 電腦在所有最佳落子中隨機挑一個，所以每局開局不會完全一樣。

## 本機執行

不需要安裝或建置，直接用瀏覽器開啟 `index.html` 即可。
