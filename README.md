# 消失井字棋 · 不敗 AI

一個單檔網頁小遊戲：可自由選擇由你先手或電腦先手，對手是用完整逆向分析（Retrograde Analysis）搜尋所有可達狀態的電腦 AI。

**線上試玩：<https://wkai2573.github.io/vanishing-tictactoe/>**

## 規則

- 棋盤與連線規則和一般井字棋相同，先連成一線者獲勝。
- 每位玩家最多同時保留 3 顆自己的棋子。
- 下第 4 顆時，自己最舊的那顆會從棋盤上消失。
- 棋盤上的小數字是棋子的年齡，黃色閃爍的格子是下一手落子後即將消失的棋子。
- 對局超過 300 手仍未分出勝負，判為和局。
- 可點擊上方的玩家標籤切換「你先手」或「電腦先手」。

## AI 原理

- 局面由雙方各自的落子順序與輪到誰決定，共有約 11.6 萬個可達狀態。
- 採用逆向分析（Retrograde Analysis）在開局以極速（約 100ms）窮舉計算所有盤面的勝負值與距離終局步數：
  - **處於劣勢時**：採取極限頑抗策略（選擇存活步數最長的路徑），逼使先手必須走出完美的 13 步唯一正解才能獲勝；若先手稍有不慎，電腦立刻扳平或反殺。
  - **處於平局時**：精準封堵所有威脅，確保 100% 守和。
  - **處於勝勢時**（如電腦執先手）：選擇最速制勝路徑迅速終結對局。
- 電腦在所有等價的最佳落子中隨機挑選，保持每局棋步的變化性。
